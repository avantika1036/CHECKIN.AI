# Repository mirror

The `backend-partial-frontend` branch is maintained in both repositories:

- Primary: https://github.com/Jeevanjot19/Checkin.ai
- Mirror: https://github.com/avantika1036/CHECKIN.AI

Push updates to the primary repository with:

```bash
git push origin backend-partial-frontend
```

Push the same branch to the mirror with:

```bash
git push friend backend-partial-frontend
```

Keep secrets in `.env`; it is excluded by `.gitignore` and must not be committed.
